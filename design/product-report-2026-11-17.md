# Stayloop 产品报告 · 四个角色的使用体验（2026-11-17）

起因：用户要求「重新核对和验证一下四个角色的使用体验，每一个角色使用体验要比传统的更加方便，先总结一下我们系统的优点，用简洁的文字描述出一个产品报告，也提出修改优化的建议」。

## 1. 这次核对了什么

- **逐页走查**：用四个测试号（租客、房东、经纪、服务商）在线上逐页打开，共 66 个页面，记录每页的内容、加载时间、报错和手机 375 宽下的排版。
- **结果**：66 页全部打开；没有脚本报错，没有失败的请求；手机上没有横向溢出，输入框字号都不小于 16px。页面可用时间中位 0.64 秒，九成在 1.6 秒内，最慢 3.0 秒（「我的筛查档案」）。
- **权限回归**：数据库权限脚本 183 项审计全过；285 条探针过 283 条，没过的两条是早就知道的测试夹具问题（那一期租金已经被记过），不是权限漏洞。
- **客观数字**：从数据库查了 AI 助理的响应时间和各目录的数据量。
- **没有重做的**：端到端流程（申请 → 签约 → 报修 → 派单 → 验收）、邮件、推送、Stripe 付款这次没有重新跑。上一次完整走通是 10-28 那轮全站测试。

## 2. 系统的优点

1. **一个人一个 AI 助理，四种身份共用。** 助理记得你说过的预算、区域和进行中的事，每天扫一遍你的数据，把该处理的事做成待办卡，等你点头。
2. **AI 只提议，人来决定。** 发消息、报修这类动作先出卡片，批准后才执行，60 秒内可撤销；录取谁、发哪张通知永远由人决定。
3. **规则写在产品里。** 押金上限、涨租比例、N 表日期、不能问的问题都是确定性的计算，带法条出处；外省按各省规则切换。助理引用的条号必须来自检索到的原文。
4. **一条事务从头到尾留痕。** 申请、租约、租金、报修、对话都挂在同一份租约上，双方看到的是同一份记录，消息只追加不能改，可以导出证据包。
5. **资质是人工核过的。** 经纪对照 RECO 注册库、服务商对照各行业公开注册库人工核验，到期自动失效；页面上写明「核验不等于推荐」。
6. **不碰钱、不抽成。** 租客永久免费；房东免费档每月 3 次筛查；平台不收租金、不抽佣金，付款都在线下直接结算。
7. **数据权限在数据库里强制。** 每张表的读写规则由数据库执行，不靠页面隐藏按钮。

## 3. 四个角色：比传统做法方便在哪

### 租客

| 环节 | 传统做法 | Stayloop |
|---|---|---|
| 申请 | 每个房东各填一遍表，证件和工资单一次次重发 | 申请包填一次；之后每次申请点「用我的申请包填写」，勾选要附的文件，提交 |
| 等结果 | 发出去就只能等 | 时间线：已提交 → 房东已查看 → 筛查已发起 → 已录取 → 租约待签 |
| 看懂租约 | 自己查法规 | 涨租通知核对、退租日期与押金利息工具；助理解释条款并给出处 |
| 入住 | 口头交接 | 13 项入住清单，双方勾选，记录谁在什么时候确认 |
| 报修 | 发短信，没有记录 | 说一句话生成工单，进度全程可见，完工后由自己确认 |
| 租金 | 转账后没有凭证 | 每期一行，可传凭证，双方确认 |
| 被筛查之后 | 不知道房东看到了什么 | 「我的筛查档案」可以索取、提争议 |

### 房东

| 环节 | 传统做法 | Stayloop |
|---|---|---|
| 发布房源 | 每个平台手填一遍 | 快速发布只填地址、月租、照片，AI 看照片填其余，自己核对后发布 |
| 收申请 | 邮件和微信里翻材料 | 按阶段分组，并排对比只列事实，可导出 CSV |
| 筛查 | 自己打电话、查信用、查法庭记录 | 上传材料，一份报告里有付款能力、信用、租务与司法历史、核验四项，另有材料真伪检测 |
| 租约 | 下载 PDF 手填，见面签字 | 起草安省标准租约并电子签；已签的租约可以导入 |
| 发通知 | 自己算日期，算错就无效 | N 表工具箱算日期、出填写稿、记送达 |
| 维修 | 到处找师傅，报价口头说 | 工单派给已核验服务商或自己的联系人；报价要批准；自动给租客发进入通知 |
| 记账 | 自己做表格 | 租金台账、报税对照表、CSV |
| 日常 | 自己记着哪天该做什么 | 助理每天扫描，租金逾期、续约窗口到了会出待办卡 |

### 经纪

| 环节 | 传统做法 | Stayloop |
|---|---|---|
| 客户管理 | 表格或通用 CRM | 客户表按阶段管理，自动生成跟进任务 |
| 合规文件 | 自己记代表协议和 Information Guide 的日期 | 每位客户一行，缺哪份、哪天到期一眼看到，到期自动出任务 |
| 收材料 | 让客户发邮件 | 发一个收件链接，材料到了一键筛查 |
| 筛查 | 找第三方或让房东自己做 | RECO 核验通过后直接做，报告记在自己名下，可委托给客户看 |
| 核对要约 | 逐条人工看 | 贴进文字，自动核对押金、费用、无效条款等，支持 13 个省和地区 |
| 获客 | 自己建网站、投广告 | 公开主页和经纪目录，咨询经站内消息直接进客户表 |
| 认证 | 传证件、等审核 | 只填 RECO 公开注册库上已有的信息，不传证件 |

### 服务商

| 环节 | 传统做法 | Stayloop |
|---|---|---|
| 入驻 | 靠口碑和熟人介绍 | 填资质编号，人工核验一次，之后按工种和城市收到派单 |
| 接单 | 电话、微信，口头约定 | 邀请 → 报价 → 房东批准 → 排期 → 到场 → 完工，每一步有记录 |
| 进门 | 自己和租客约 | 报价批准后系统给租客发进入通知，写明日期和时段 |
| 结算 | 追着要钱，没有凭据 | 账单不得超出批准报价 10%；验收回执；平台不抽成 |
| 口碑 | 说不清 | 响应时长、准时率、接单率、评价都从自己的工单算出来 |
| 资质管理 | 自己记到期日 | 到期前 90、60、30、7 天各提醒一次 |

## 4. 核对中发现的问题

按影响从大到小排。

1. **目录里没有真实内容。** 公开房源 6 套全是测试房源；已核验服务商 3 家全是测试数据；已核验经纪 3 位，真实的只有 1 位；专业服务四个类别是空的。账号共 24 个，10 个是测试号。产品做得再顺，新用户进来也没有东西可用，这是现在最大的短板。
2. **AI 助理回复慢，而且是整段一次出来。** 最近 30 小时 33 次对话全部成功，中位 9.4 秒，九成在 18 秒内。等待时只有一行状态字。
3. **中英文混在一起。** 租金逾期的待办卡标题是「中文 / English」两种语言并排（房东的待办页和想法页都能看到）；经纪的筛查页顶部提示也是中英并列；用英文聊出来的卡片在中文界面里显示英文。
4. **「迟付」被标成「逾期」。** 租客的租金页把已经付清、只是晚了几天的那几期显示成红色的「逾期」；同一期在房东端显示的是「已付 · 迟付」。租客会以为还欠着钱。
5. **示范内容和真实记录混在同一页。** 测试租客已经有真实的在管租约，但租约页的大标题仍是示范的「Unit 1207 · King West 租约」，顶部写着「本页显示的是产品示范」。
6. **空页面占着导航位。** 经纪的「日历」和「佣金」各只有一句话。佣金页写的是「完成的转介与筛查服务会在这里对账」，而平台并不结算佣金。
7. **服务商没有自己的导航。** 其他三个身份有工作台侧栏，服务商没有；在手机上，纯服务商账号底部显示的是租客工作台的四个标签（AI 助理、待办、想法、进度），自己的工单要到「更多」里找。
8. **给已核验的经纪推荐去做核验。** 经纪的想法页里有一条「RECO 注册核验：认证后进入租客可选的经纪目录」，这个账号早已核验通过。
9. **一句文案说过头。** 房东租约页副标题写「续约 / 涨租通知一键发送」，而涨租通知是 LTB 的官方表格，平台只算日期和出填写稿，不代发。

## 5. 改进建议

**马上能改的小问题**（都是文案或显示，不涉及流程）
- 第 3 条：待办卡标题分开存中英文，按界面语言显示；经纪筛查页的提示同样处理。
- 第 4 条：租客端的「逾期」改成「已付 · 迟付」，和房东端一致。
- 第 6 条：经纪侧栏先拿掉「日历」和「佣金」，等有真实功能再放回；佣金页那句话删掉。
- 第 8 条：想法页按核验状态过滤。
- 第 9 条：副标题改成「续约提醒 · 涨租日期核对」之类属实的说法。

**值得做的体验提升**
- 第 2 条：助理的回复改成边生成边显示，目标是 2 秒内出第一个字。这是四个身份每天都会碰到的等待。
- 第 5 条：账号有真实租约时，租约页、维修页、租金页不再显示示范内容。
- 第 7 条：给服务商一套自己的导航（工单、历史、资料、消息、找人），手机底栏也跟着换。
- 申请页：已有申请包的租客打开申请页时直接填好，不用再点一下「用我的申请包填写」。

**需要你决定或依赖外部的**
- 第 1 条：先在一个小范围把供给做起来，比如多伦多北部先找 10 位经纪、10 家服务商、20 套真实房源，再对外推广。这是运营的事，不是代码的事。
- 核验章要等 Veriff、Flinks、Equifax 的生产凭证和 CRA 注册；这些到位之前，「核验」这一项对用户的价值是打折的。
- 经纪目录要不要显示电话（昨天定的是先不显示）可以在有了真实经纪之后再看反馈。

## 6. 结论

流程本身比传统做法省事，四个身份都成立：材料只交一次、进度看得见、规则自动算、每一步有记录。页面质量过关，这次 66 页没有发现打不开或排版坏掉的。

现在拖后腿的不是功能，而是三件事：目录里没有真实的房源、经纪和服务商；助理要等十秒左右；还有一批文案和显示上的小毛病会让人对「这是不是真的」产生怀疑。前两件决定用户留不留得下来，第三件一天就能清掉。
