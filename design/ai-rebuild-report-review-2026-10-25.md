# 《AI 重构租房业务报告（新版）》对照 Stayloop 现状 · 改进方案（2026-10-25 · 待用户确认）

报告：`~/Downloads/AI 重构租房业务报告（新版）.html`（调研基准日 2026-10-24，15 节）。本文把报告的每条建议对照现在的代码与守卫，分成「已有 · 补一块 · 新做 · 不做」，再排成三批，最后列出要用户拍板的事。**确认前不动代码。**

## 一句话结论

报告的主干——「正确性 + 证据台账是产品；房源在平台生成一次、向外分发、手续回流」——Stayloop 已经按这条线建了大半：规则引擎按生效日期版本化（Bill 60 的 N4 7 天、15 天复审、持续迟付、付款协议表都在 `lib/ontario/rules.ts`），哈希链消息台账，证据包导出，快捷发布（视觉读照片 + 合规检查），MLS 交接，手动分享线，服务商资质阶梯，经纪公开主页，消费者档案，免密钥开放 API。报告「不建清单」里的八项我们一项都没碰。

真正的差距集中在五处：**① 面向人的免费工具页**（现在只有给机器的 API 和一页规则列表）；**② 分享包只有一版文案、没有渠道归因与下架闭环**；**③ 服务商广场缺「专业服务」类目与流程节点触发**；**④ 入住 / 退租照片没进台账**；**⑤ 财务页承诺的 T776 导出还没兑现**。另外报告有几处与我们的既定边界冲突（PAD 收租、VR 默认开启、Realtor.ca 渠道），下面写明不采纳的理由。

## 报告里不采纳或要纠正的点

- **PAD / Interac 收租**：报告把它当标配。Stayloop 不经手资金是既定决策（FINTRAC + RPAA），只做记录与凭证。
- **VR 轻档默认开启**：生成内容默认出现在房源页，与报告自己的 RECO 红线矛盾。只接受 opt-in + 标注。
- **Realtor.ca / DDF 作为分发渠道**：PropTx 2026-10-13 已拒绝，MLS 读取永久关闭，不再提。
- **Bill 60 终结固定期转月租**：报告标为未核实；我们规则库已写明「未获通过，仍有效」（`RTA-38-month-to-month`）。
- **厂商自报数字**（EliseAI、AppFolio、ShowMojo 等）：不进任何用户可见文案（已有「不编造数字」规则）。
- **报告把 Paralegal 证据包定价 $199–299**：我们证据包免费给当事人，转介不收费。

## 建议的实施顺序

每批都能单独上线；工时是我的估算（含测试与守卫）。

**第一批（纯站内、无外部依赖，约 5–6 个工作日）**
1. 公开工具页：N4 / N1 / N12 日期算术、要价对照、「我能问这个吗」；`/rules` 加更新记录与官方链接。
2. 分享包 v2：按平台的文案版本、二维码海报、每渠道短链与点击归因、回复模板。
3. 回流闭环：手动渠道贴回链接；下线 / 签约时的「下架清单」待批卡。
4. 房东月度简报例行任务。
5. 两张小卡：续约页空置成本对照；逾期次日事件卡。

**第二批（新数据与类目，约 7–9 个工作日）**
6. 专业服务类目（Paralegal / 律师 / 保险经纪 / 摄影户型图）+ 两张节点触发卡 + 经纪卡片站内信号。
7. 入住 / 退租照片入台账 + 并排对照。
8. T776 年度导出。
9. 证据包按事务类型排序 + Paralegal 转介出口。
10. 筛查方法论公开页（文案）；房源「首次入住日期」勾与声明；定价参考卡。
11. 房源页「问 AI」只答记录内事实（需先定边界）。

**第三批（外部依赖，等用户动作或回信）**
12. Meta Page + IG 自动发（用户建 Meta Business 账号、App 审核）；Rentsync / Kijiji feed（等回信与专业账户）。
13. 户型图采集经广场下单；VR 轻档 opt-in 试跑 5 套（Marble Pro 由用户决定是否订）。
14. 直发 Pro（Ayrshare）——不早于 18 个月。

**不做**：虚拟布置（暂）、照片增强、动态定价、租金担保、租金上报、PAD 收租、AI 损坏评级、L1 / L2 生成、自研 3D。

## 需要用户拍板的事

1. 第一批的 5 项是否全做、顺序是否同意。
2. 定价：免费档用完后加不加「单次筛查 $29.99」购买项。
3. 专业服务类目开不开：每个 Paralegal / 保险经纪的牌照都要人工核（LSO / RIBO 公开名册），和经纪一样不自动查。
4. 公开工具页的名字与入口：页头菜单不动，入口放「产品」页与 `/rules` 内，还是另开一级路由（建议 `/tools`，中文名「租房小工具」）。
5. 月度简报：新房东默认开，还是像其他例行任务一样自己开（建议自己开，避免没数据的空简报）。
6. 房源页「问 AI」要不要做；若做，AI 只答记录内事实、政策类一律转房东。
7. VR：是否现在就订 Marble Pro 试跑 5 套，还是整条线等房源量上来再说（建议等）。
