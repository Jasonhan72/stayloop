# 经纪目录页与经纪主页 · 改版方案（2026-11-17，已定稿并实现）

起因：用户发来 Realtor.ca 的经纪搜索结果页和经纪主页截图，要求「再研究一下经纪的现实页面和方式，再找几个网站做一下研究，要改进现有的页面布置设计」。

**2026-11-17 定稿**：用户「按建议实现」，第 5 节三处都按建议定，当天实现（ship118–119）。和方案不同的只有一处：主页照片在手机上用 88px（方案写的是统一 128px），否则姓名会被挤到照片下面。

**至少三家共有的做法**
- 桌面两列卡片，照片在左（Royal LePage、Centris、Zillow、Redfin，加上 Realtor.ca）。
- 搜索以「区域 + 姓名」为主，语言是第一个筛选项。
- 卡片上有明确的联系按钮，点了走平台的表单；多数同时有「看主页」。
- 每张卡片都有经纪公司名，法定头衔写在姓名下面。
- 主页顺序：头部（带联系）→ 简介 → 语言 / 区域 / 专长 → 房源。
- 排序都很弱，没有一家标「赞助」；Centris 干脆随机。

**做得好的页面比「姓名 + 公司 + 徽章」多出来的东西**
1. 牌照号写成能核对的事实（Redfin、RE/MAX、Centris）。
2. 卡片上两个按钮：看主页、直接联系。
3. 语言和服务区域既是筛选项，也直接显示在卡片上。
4. 卡片上有平台自己的活动数字（成交数、主要区域）。
5. 联系入口一直在手边（侧栏固定，或手机底部固定）。

## 2. 现在的页面差在哪

**目录页 `/agents`**
- 三列小卡片，一个人占三分之一宽，头像 48px，看起来像占位。
- 卡片上没有按钮，整张卡片是个链接，看不出能直接发消息。
- 不能按姓名或经纪公司找人。
- RECO 注册号藏在徽章的悬停提示里。
- 没开主页的经纪单独放在下面一节，像次一等的名单。
- 没有「共几位」，也没说按什么排序。

**主页 `/agents/[slug]`**
- 头像 72px 的圆形，头部偏空；经纪公司和头衔挤在一行。
- 头部没有联系按钮，手机上联系表单要滑到最底。
- 一大块绿色的核验说明占了头部最显眼的位置。
- 语言只是一行字；专长、区域在很下面。
- 房源卡片很小（缩略图 112×80）。
- 没有分享按钮。

## 3. 目录页改成什么样

**搜索与筛选**（一行，手机上换行）
- 区域（现有）、姓名或经纪公司（**新增**）、语言、专长。
- 按姓名或公司搜时，没开主页的经纪也参与匹配；按语言、专长、区域筛时只看开了主页的（其余的没有这些信息）。

**结果行**
- 左边：「共 3 位经纪，其中 1 位可以在站内联系」。
- 右边：排序下拉，「默认」和「姓名 A–Z」两项。
- 下面一行小字写明默认顺序：「开了主页的在前，其次按核验时间；没有推荐位，也不收排名费。」

**卡片**（桌面两列，手机一列；所有经纪在同一个列表里）
- 左边：照片，88px 圆角方形（现在上传的照片本来就裁成方形）；没照片的用姓名首字母。
- 右边从上到下：
  - 姓名
  - 法定头衔（+ REALTOR®）
  - 经纪公司名（加粗，单独一行）
  - 「✓ RECO 注册已核 · #注册号」，点了去 RECO 注册库
  - 语言标签、专长标签、服务区域（最多 3 个，其余「+N」）
  - 经纪选择公开时：一行站内数字（筛查、签约、回复中位时间）
- 底部两个按钮：「看主页」和「发消息」。「发消息」直接到主页的联系表单。
- **没开主页的经纪**用同样的卡片：头像是灰色首字母，右上角标「未开主页」，没有标签和数字，底部只有一个链接「在 RECO 注册库核实 ↗」。排在开了主页的后面，不再单独分一节。
- 测试数据的「测试数据」标签保留。

## 4. 主页改成什么样

**头部**
- 照片放大到 128px 圆角方形。
- 经纪公司名单独一行、加粗，紧跟在头衔下面（RE/MAX 把公司名放在姓名上面；我们放在下面但同样醒目，满足「清楚而显著地标明经纪公司」的广告要求）。
- 一行事实：「RECO 注册已核 · #注册号 · 核于 日期」「语言」「加入时间」。
- 两个按钮：「发消息」（跳到联系表单）、「分享」（复制链接）。
- 那一大块绿色核验说明移到页面下部的「注册与核验」一节。

**各节顺序**
1. 头部
2. 关于我
3. 服务信息：语言、专长、服务区域，三项并排
4. 在租房源：三列，照片放大
5. 在 Stayloop 上：三个数字（经纪选择公开时）
6. 注册与核验：注册号、类别、经纪公司、核验日期，「在 RECO 核实」「向 RECO 投诉」，以及「核验不等于推荐」那句话
7. 页脚声明（Stayloop 不是经纪公司……）

**联系**
- 桌面：右侧联系表单保持固定跟随（现有）。
- 手机：头部的「发消息」按钮跳到表单；房源一节后面再放一个。不做底部固定条，因为登录后的手机底部已经有工作台导航栏，两条会叠在一起。
- 表单内容和发送后的提示不变。

**不变的**
- 联系只走站内消息，主页不显示邮箱和电话（第 5 节第 1 处）。
- 不放评分、不放成交额：我们没有这些数据，也不编。
- 不做推荐位和排名。

## 6. 实现范围（定稿后）

- `/agents`：筛选行加姓名搜索；结果行与排序；卡片改成两列的横向卡片；两类经纪合并成一个列表。
- `/api/agents`：加 `q`（姓名或公司）参数，对两类经纪都生效。
- `/agents/[slug]`：头部重排；各节顺序调整；房源卡片放大；加分享按钮；「注册与核验」一节。
- 头像组件支持圆角方形。
- 没有数据库迁移。
- 守卫：目录页、主页现有的几条守卫要同步改；新增卡片、排序、搜索、主页头部的测试。
- 手机 375 宽、中英文各走一遍；一次部署。

## 7. 这次不做

- 经纪公司的办公地址、电话、标志：我们没有收集，要加得新增字段并人工核对。
- 评分、评价、成交数据。
- 联系表单里问「你现在有没有合作的经纪」（Royal LePage 有）：可以以后加。
- 手机底部固定的联系条。
