# 经纪怎么用 ChatGPT — 来源摘要（2026-10-13）

- **NAR 2025 技术调查**（nar.realtor 新闻稿，2025-07 抽样 49,233 人、1,241 份有效）：20% 每天用 AI、22% 每周、27% 每月几次、32% 没用过；用的工具 ChatGPT 58%、Gemini 20%、Copilot 15%；46% 用过 AI 生成内容（如房源描述）；17% 说「显著正面」、33%「中度正面」、46%「没有明显影响」。
- **REM（realestatemagazine.ca）David Ursino 2026-10-01「AI use is up. The results aren't.」**：引更新一版 NAR 数据——写房源描述 75%、社媒 56%、邮件跟进 52%；定价 / 可比 23%、线索 11%、客户状态自动更新 9%、**填表 7%**；采用动机省时间 81%；障碍是学习曲线 63%、成本 59%；「Canada has no equivalent scorecard」（CREA / 各 board / RECO 都没有加拿大数据）。引语："writing is the cheapest part of this job"。
- **REM Ursino 2026-07-27「AI will agree with you right up to the complaint」**：经纪在 Facebook 群贴出 AI 答案称 TRESA 禁止给未代表的买家带看、还附了 RECO 公告与律所引用，被有经验的经纪与律师指出是错的；引语："AI is a genuinely great tool. It is also a sycophant." / "Ask sharper questions. Trust the answers less."
- **博客类**（nowbam.com、agentfire.com、luxurypresence.com）：用途集中在房源描述、跟进邮件、社媒文案、社区介绍、披露文件摘要；多篇强调「every output should be reviewed, fact-checked, and edited」；一篇指出 ChatGPT「cannot access live MLS data」。
- **社区（Reddit）**：reddit.com 对本调研的抓取返回 403，r/TorontoRealEstate 原帖未能读取。
- 对我们的含义：经纪已经在用通用模型写文案；他们缺的不是「再一个聊天框」，而是**不会把 TRESA 答错**（每条答案带法条与 RECO 公告出处）和**能填表**（7% 的人在用 AI 填表，说明需求存在但工具没接上）。
