# V0.8 · 消费者索取档案与争议更正（方案 · 2026-10-12）

依据：安省《消费者报告法》s.12（索取档案）、s.12.1–12.3（身份警示）、s.13（争议与更正）、s.9（档案标准）、s.11(3)（提供前确认用户已通知消费者）。
研究稿 `design/consumer-reporting-act-research-2026-10.md`。目标：注册前就把注册后必须有的流程做出来，无论注册何时完成，申请人今天就能行使这些权利。

## 法条要求 → 产品要求

| 法条 | 要求 | 我们要做的 |
|---|---|---|
| s.12(1)(a) | 消费者可书面或电子请求自己的「消费者报告」 | 公开入口 `/my-file`，不要求先有账号 |
| s.12(3) | 披露：档案里关于他的全部信息的性质与实质；信用信息来源；3 年内每一个代表其查阅档案的人的姓名与电话；1 年内收到报告的人的姓名电话 + 报告副本 | 披露包 = 筛查报告（含抽取事实、取证标记、公开记录命中）+ 来源清单 + 查阅记录（房东、分享链接打开、合作方 API） |
| s.12(6) | 消费者须提供身份证明；机构可合理要求其他证明 | 申请邮箱一次性验证链接 + 姓名 + 出生日期与档案比对；对不上时人工复核 |
| s.12(7)–(8) | 消费者选电子 / 邮寄 / 电话；电子须在 2 个工作日内发出 | 默认电子（登录后页面 + PDF），邮寄与电话走管理员队列并记时限 |
| s.12(5) | 披露时告知争议权与争议方式 | 披露包首页固定段落 + 每条可争议 |
| s.12(9)(11) | 浅白语言；有受训人员解释 | 披露包用报告的中文 / 英文本地化层；「联系 Stayloop」对话（support thread）作解释渠道，答复由指定人员处理 |
| s.12(13) | 不得收费 | 免费 |
| s.13(1) | 争议任一项的准确性或完整性 → 合理时间内尽力核实，更正 / 补充 / 删除 | 逐项争议工单；管理员核实；结果写回筛查行并在报告上显示更正注记 |
| s.13(2) | 更正后通知：60 天内收到报告的所有人；消费者指定的 1 年内（个人信息）/ 6 个月内（信用信息）收件人 | 自动找收件人（房东、经纪、分享链接与 API 合作方）并发邮件；记录通知时间 |
| s.12.1–12.2 | 身份警示：消费者可要求在档案里放警示，之后每次披露都要带 | `consumer_alerts` 表；报告与 API 响应顶部显示警示 |
| s.9(3)(b) | 不利个人信息未经佐证须注明 | 已有（LTB / 法院同名命中标「未佐证」），披露包沿用 |
| s.9(3)(c)(f)(i)(k) | 判决 / 债务 7 年；令状与诉讼超 12 个月须核实现状；其他不利信息 7 年 | 公开记录命中带日期过滤；法院门户命中超过 12 个月在再次使用前重查 |
| s.11(3) | 提供信息前须有理由相信房东已通知申请人 | 发起筛查时房东确认「申请人已收到书面通知（Form 410 或申请页同意）」并记录 |

## 分四步做

1. **数据与记录补齐**（无界面）：`consumer_file_access` 视图 / 函数——按申请人（姓名 + 邮箱 + 出生日期）汇总其在 `screenings`、`applications`、`verification_requests`、`passport_share_tokens` 里的行；查阅记录统一从 `agent_audit_events`（`application_file_viewed`、`trust_api_passport_verify`、`listing_viewed` 不算）与 `passport_share_tokens.view_count` 推导，分享链接打开改为逐次记录（时间 + 来源）；房东资料补「联系电话」（披露要列查阅者电话）；筛查发起时记录 s.11(3) 确认。
2. **申请人入口 `/my-file`**：输入申请时的邮箱 → 一次性验证链接（24 小时）→ 填姓名 + 出生日期 → 匹配到的筛查列表 →「索取我的档案」（电子：立即生成披露包页面 + PDF；邮寄 / 电话：进队列）。披露包 = 浅白语言的档案摘要 + 原报告 + 来源 + 查阅记录 + 争议入口。匹配不到或信息对不上 → 工单给管理员人工处理（2 个工作日时限显示在队列里）。
3. **争议与更正**：披露包里每一条事实 / 公开记录命中 / 取证标记旁「这条不对」→ `consumer_disputes`（item 引用 + 申请人说明 + 可附证明）→ `/admin/consumer-requests` 队列（请求与争议同一队列，时限倒计时）→ 管理员核实后选择「更正 / 补充 / 删除 / 维持（写明理由）」→ 结果写入 `screenings.corrections`（只追加）并在报告、PDF、API 响应上显示更正注记；自动通知 60 天内的收件人（房东邮箱、经纪、API 合作方 webhook、分享链接持有者不可达则记录）；申请人收到结果邮件。
4. **身份警示 + 公开说明页**：`/my-file` 里可设置 / 撤销身份警示（s.12.1，6 年到期）；报告、PDF、护照 API 响应顶部带警示；`/consumer-rights` 页用浅白语言写清三项权利、时限、联系方式，通知信与报告页脚链到它。

## 不做 / 留到注册后
- 消费者评分披露（s.12(4)）只对 Equifax / TransUnion 规定（Reg. 177 s.10.1），不做。
- 邮寄与电话披露只做队列与记录，不做自动化。
- 外省申请人：筛查暂只对安省房东开放，魁北克 CAI 登记另议。

## 验收
- 申请人用申请邮箱在 2 个工作日内（电子方式即时）拿到披露包，包含 3 年内查阅者姓名电话与 1 年内报告副本。
- 一条争议从提交到更正后，原报告显示注记、60 天内的收件人收到通知邮件、审计可查。
- 守卫：披露包不含任何其他申请人的数据；未验证邮箱不能看到任何档案；更正只追加不覆盖。
